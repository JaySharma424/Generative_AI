An enterprise-grade Retrieval-Augmented Generation (RAG) and AI Workflow platform built for secure, grounded, and role-based knowledge synthesis across organization-wide documents.

This repository features a complete end-to-end architecture including automated multi-modal document ingestion, semantic chunking, vector indexing with ChromaDB, RBAC-enforced query classification, hybrid dense/sparse search, grounded synthesis with anti-hallucination guardrails, and automated citation formatting delivered through an interactive Streamlit UI.

## 🏢 Executive Overview

In large enterprise environments, sensitive operational knowledge is fragmented across engineering specifications, HR policies, execution frameworks, sales presentations, and incident SOPs. Accessing this information efficiently while strictly maintaining **Role-Based Access Control (RBAC)** and preventing **LLM hallucinations** is critical.

This platform provides:
* **Grounded AI Synthesis:** Guarantees every statement generated by the LLM is directly verifiable against retrieved source context.
* **Strict RBAC Enforcement:** Filters vector space and document access based on user authorization roles (e.g., Engineering, HR, Sales, Ops).
* **Verifiable Citations:** Automatically attaches precise metadata and page/section citations to generated answers.
* **Production-Ready UI:** Streamlit interface configured for multi-user enterprise interactions.

## ✨ Key Features

| Feature Component | Description |
| :--- | :--- |
| **RBAC Query Classifier** | Analyzes incoming user prompts against user roles to enforce access policies prior to retrieval. |
| **Hybrid Vector Retrieval** | Blends dense vector embedding similarity search with metadata filtering using ChromaDB. |
| **Grounded Synthesis Engine** | Restricts LLM output generation strictly to retrieved context blocks to prevent hallucination. |
| **Citation Builder** | Dynamically formats and maps in-text citations to raw enterprise source files and metadata. |
| **Document Processing Pipeline** | Automated PDF parsing, semantic chunking, and embedding generation. |
| **ChromaDB Vector Storage** | Persistent SQLite-backed vector store holding high-dimensional document embeddings. |

## 🔄 Pipeline & Workflows

### 1. Data Ingestion & Indexing
The ingestion workflow reads raw documents from the `data/` folder, parses content into clean markdown/text blocks, applies semantic chunking, generates embeddings, and indexes them into ChromaDB:

```bash
python -m ingestion_pipeline.embedding_jobs.vector_indexer
```

### 2. RBAC Query Classification
Before performing database lookups, the query classification module (`ai_workflows/query_classification/rbac_classifier.py`) checks user credentials against target domain tags:
* Restricts HR sensitive documents to authorized HR personnel.
* Restricts internal engineering specs and SOPs to technical leads.

### 3. Hybrid Retrieval
`ai_workflows/rag_retrieval/hybrid_search.py` performs top-$k$ similarity queries over ChromaDB while applying role-based metadata filters:
```python
from ai_workflows.rag_retrieval.hybrid_search import HybridSearchEngine

search_engine = HybridSearchEngine(db_path="vector_db/")
results = search_engine.query(
    query_text="What is the Sev-1 incident response SLA?",
    user_role="Incident_Manager",
    top_k=5
)
```

### 4. Grounded Synthesis & Citation
`synthesis_engine.py` constructs a strict prompt incorporating retrieved context blocks, enforcing zero external assumptions. `citation_formatter.py` cross-references cited source fragments back to the original source files and page numbers.

## ⚙️ Installation & Setup

### Prerequisites
* Python 3.10, 3.11, or 3.14+
* Virtual environment tool (`venv` or `conda`)

### Installation Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-organization/enterprise-ai-workflows.git
   cd enterprise-ai-workflows
   ```

2. **Create and Activate a Virtual Environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate        # On Linux/macOS
   # or
   .\venv\Scripts\activate       # On Windows
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
   *(Ensure dependencies such as `streamlit`, `chromadb`, `pydantic`, `langchain`/`llama-index`, and `pypdf` are installed)*

## 🚀 Usage Guide

### Launching the Streamlit Application

Run the following command to start the interactive web application:

```bash
streamlit run app.py
```

Open your browser and navigate to `http://localhost:8501`.

### Interacting with the Assistant
1. **Select User Role:** Choose your enterprise persona in the sidebar (e.g., *Engineering Lead*, *HR Partner*, *Sales Executive*).
2. **Submit Query:** Enter natural language questions such as:
   * *"What are the escalation timelines for a Sev-1 outage?"*
   * *"Summarize the parental leave policy for 2026."*
   * *"What cloud migration frameworks are outlined in our sales deck?"*
3. **Review Grounded Output:** Examine the generated response alongside source tags and verifiable document citations.

## 🔒 Security & Compliance

* **Data Isolation:** Metadata filtering prevents cross-domain data leakage across role boundaries.
* **Grounded Integrity:** Strict system prompts prevent hallucinated data generation.
* **Local Vector Store:** ChromaDB operates in local/persistent mode, ensuring sensitive corporate documents remain within security perimeters.
